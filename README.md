# לוח דיגיטלי לבית כנסת — גרסה 1.0

מערכת מלאה לבית כנסת אחד: ממשק ניהול בעברית (RTL) לכל התכנים, תצוגת טלוויזיה 16:9 עם שעון חי ומעבר אוטומטי בין מסכים, ועבודה מלאה גם ללא אינטרנט.

```
Admin (React)  ──►  API (FastAPI)  ──►  PostgreSQL
                       │
TV Display (React PWA) ◄── snapshot גרסאי + checksum ── נשמר ב-IndexedDB + Service Worker
```

## מה כלול

| רכיב | תיאור |
|---|---|
| `backend/` | FastAPI + SQLAlchemy 2 + Alembic. 35 טבלאות, אימות מנהלים (Argon2id), sessions, CSRF, טוקני התקן לטלוויזיה, יומן פעולות, מנוע זמני הלכה ולוח עברי, snapshot לתצוגה. |
| `apps/admin/` | ממשק ניהול React + TypeScript + TanStack Query, רספונסיבי למחשב ולנייד. |
| `apps/display/` | תצוגת TV React + TypeScript, ‏1920×1080 עם התאמה ל-4K, PWA עם Service Worker ו-IndexedDB. |
| `web/` | nginx שמגיש את שני הממשקים ואת ה-API **מאותו מקור** + Caddy אופציונלי ל-HTTPS אוטומטי. |
| `e2e/` | בדיקות דפדפן אמיתיות (Playwright): ממשק ניהול, ניתוק רשת, הפעלה מחדש ללא רשת, סנכרון. |
| `scripts/` | גיבוי מוצפן ושחזור, הרצה מקומית, הפעלת קיוסק, המרת ייצוא ספריא לייבוא הלכות. |
| `docs/` | מסמכי הפעלה, אבטחה, מנוע הזמנים, התקנת קיוסק וסטטוס דרישות. |

## מודולים בממשק הניהול

לוח בקרה · תצוגה מקדימה · **מסכים** (הפעלה/כיבוי, גרירה לשינוי סדר, משך בשניות, תבנית, תנאי הצגה לפי ימים/שבת/שעות/תאריכים, הודעה חלופית) · **הודעות** (עורך טקסט מסונן, תמונה, תוקף, עדיפות, שכפול, הסתרה בשבת, שיוך למסכים) · **זמני תפילות** (מניינים, שעה קבועה או יחסית לזריחה/שקיעה/צאת הכוכבים וכו׳ עם הפרש ועיגול, ימים מיוחדים שמחליפים זמנים רגילים, חריגים בתאריך, ייצוא לאקסל) · **שיעורים** · **עילוי נשמת** (תאריך עברי, אזכרות, מדיניות אדר) · **זמני היום** (בחירת זמנים, שיטות חישוב, הוספות בתפילה, תזכורות, לימוד יומי) · **הלכות** (ספרים עם רישיון, נושאים, פרקים, תגיות, חיפוש, ייבוא JSON/CSV, בחירה רציפה/אקראית ללא חזרות) · **פרנסים והקדשות** · **ימי הילולה** (צדיקים, תאריך עברי, תולדות, קטע לימוד, תמונה, תצוגה מקדימה לשתי התבניות) · **ימי הולדת** · **תוכן תורני** · **מסכי טלוויזיה** (צימוד, מצב חיבור, ביטול/החלפת קוד) · **תחזוקה וגיבוי** (מצב מערכת, גיבוי/שחזור, יומן פעולות) · **משתמשים** (מנהל/עורך) · **הגדרות כלליות**.

## מסכי התצוגה

שעון גדול עם תאריך עברי ופרשה · זמני היום + לימוד יומי + פרטי היום · תפילות ושיעורים · הודעות · הלכה יומית · עילוי נשמת (רשימה/כרטיסים/לוח זיכרון) · פרנסים · ימי הולדת · **יום הילולה** · שבת וחג · מסך משולב · תוכן תורני.
בכל המסכים: סרט עליון עם שעון חי, תאריך עברי ופרשה, ולוחית הקדשה מתחלפת בתחתית.

**יום הילולה — שתי תבניות אוטומטיות:** עם תמונה תקינה — התמונה **מימין** (38%, ללא מתיחה) והטקסט **משמאל**; בלי תמונה, או אם היא חסרה/פגומה/לא נשמרה במכשיר — שם הצדיק בכותרת ממורכזת **למעלה** והטקסט **על כל הרוחב**. התבנית נקבעת לפני הציור (ללא הבהוב). טקסט ארוך מוקטן בגבולות קריאות ואם צריך מחולק לעמודים — לא נחתך.

## הפעלה ב-Render (הכי פשוט)

הקובץ `render.yaml` מגדיר את כל ההתקנה. מעלים את הקוד ל-GitHub, ואז ב-Render: **New ← Blueprint**, ומזינים סיסמת מנהל. המדריך המלא: **`docs/RENDER.md`**.

## הפעלה מהירה (Docker)

```bash
cp .env.example .env          # לשנות סיסמאות!
docker compose up --build -d
# ממשק ניהול:  http://localhost:8080/admin/
# תצוגה:       http://localhost:8080/display/
# API docs:    http://localhost:8080/api/... (ו-/docs דרך הקונטיינר api)
```
בהפעלה הראשונה נוצר מנהל לפי `ADMIN_USERNAME`/`ADMIN_PASSWORD`. לתוכן דוגמה (מסומן בבירור כ"דוגמה") הגדירו `SEED_DEMO=true`.
**פרודקשן עם HTTPS:** הגדירו `DOMAIN` ו-`COOKIE_SECURE=true`, הפנו את הדומיין לשרת והריצו `docker compose --profile https up -d` (Caddy מנפיק תעודה אוטומטית). ראו `docs/OPERATIONS.md`.

## הפעלה ללא Docker (כך נבדקה המערכת בסביבת הפיתוח)

```bash
# PostgreSQL 16:
createuser -P synagogue && createdb -O synagogue synagogue
cp backend/.env.example backend/.env   # לעדכן DATABASE_URL
./scripts/run-local.sh                 # בונה את שני הממשקים, מריץ migrations ומפעיל על http://127.0.0.1:8000
(cd backend && python -m app.cli create-admin --username admin)
(cd backend && python -m app.cli seed-demo)   # אופציונלי
```

## חיבור טלוויזיה

1. בממשק הניהול: **מסכי טלוויזיה ← יצירת קוד התקן**. מוצגת כתובת צימוד (פעם אחת בלבד).
2. בהתקן ה-HDMI (Android TV Box / Mini PC) פותחים את הכתובת. הקוד נשמר בהתקן ונמחק מהכתובת. **אין להזין סיסמת מנהל בטלוויזיה.**
3. מצב קיוסק והפעלה אוטומטית: `docs/KIOSK_SETUP.md`.

## עבודה ללא אינטרנט

- כל נתוני התצוגה (הגדרות, מסכים, הודעות עם תוקף, הלכות מתוכננות, אזכרות, הילולות, תפילות ושיעורים מחושבים, **זמני היום ל-400 יום**) מגיעים כ-snapshot אחד בגרסה, מאומת ב-SHA-256, ונשמר ב-IndexedDB בהחלפה אטומית. נשמרת גם הגרסה הקודמת.
- Service Worker שומר את האפליקציה, הגופנים והתמונות — הדף נטען מחדש גם ללא רשת וגם אחרי הפעלה מחדש של הדפדפן.
- השעון רץ לפי שעון ההתקן. הודעות פגות, מעבר יום עברי בשקיעה וחלון השבת מחושבים מקומית.
- חזרת רשת: ניסיון חוזר עם backoff, אימות גרסה, החלפה רק אחרי בדיקת checksum — ללא מסך ריק.
- אין נתונים בהתקנה ראשונה: מוצג שעון ומסך תחזוקה ברור — לא נתונים מומצאים.
- דרישה: HTTPS (או localhost) — Service Worker לא פועל ב-HTTP על כתובת רשת מקומית. דיוק השעון אחרי הפסקת חשמל ממושכת ללא רשת תלוי ב-RTC עם סוללה.

## בדיקות

```bash
cd backend && python -m pytest -q                       # 33 בדיקות: מנוע זמנים, תזמון, אבטחה וכל ה-API מול PostgreSQL אמיתי
cd apps/display && npm test                             # 13 בדיקות: לוגיקת תצוגה, חלון שבת, playlist, SHA-256
BASE_URL=http://127.0.0.1:8000 ADMIN_PASS=... python -m pytest e2e -q   # 11 בדיקות דפדפן (Chrome)
```
בדיקות ה-E2E כוללות: צימוד, Service Worker, **ניתוק רשת ורענון**, **הפעלה מחדש של הדפדפן ללא רשת**, שעון וסבב מסכים ללא רשת, תמונות מהמטמון, **ניתוק באמצע הורדה**, **snapshot פגום שנדחה**, סנכרון אוטומטי בחזרת הרשת, שינוי בניהול שמגיע לטלוויזיה, 4K ללא גלילה, תמונה מימין וטקסט משמאל, מעבר אוטומטי לתבנית ללא תמונה, טפסי ניהול ותצוגה בנייד.
